Typography

Good typography makes an interface feel effortless. A restrained scale, comfortable line lengths, and deliberate spacing help people find what matters and read without distraction.

The details should support the content. Give every element enough space to be understood, and every page a clear place to begin.

Control density

Compact — toolbars and desktop apps
Comfortable — forms and touch screens

Set density="compact" or density="comfortable" on a container to size its controls together. A label tag wraps a real, keyboard-accessible file input; visually-hidden keeps it available to assistive technology.

Loading

loading draws the spinner; aria-busy="true" carries the meaning. Use both. aria-busy is a true/false state, so it cannot be a styling hook on its own. On a button, link or summary the spinner replaces the icon rather than sitting next to it. With reduced motion enabled, the spinner keeps turning gently while decorative animations stop. Add disabled to a busy button to prevent keyboard activation.

    A popover opens centred above its anchor. placement moves it: top or bottom, on their own or with -start / -end to line its edge up with the anchor's. Anchored placement is progressive enhancement — engines without CSS anchor positioning centre the popover in the viewport instead, and where it is supported a popover near an edge flips to the other side rather than opening off-screen. The layout attributes work inside one: this menu is a col gap. Use placement="center" for a viewport-centred popover.

    responsive gives a too-wide table its own horizontal scrollbar so it can never stretch the page; pair it with white-space: nowrap if you want the columns to keep their natural width instead of cramming. Prefer it on a wrapper — <div responsive> — because on the table itself it has to switch the table to a block box, which makes the columns shrink to their content. responsive="stack" instead breaks each row into its own card under 600px, printing every cell's data-label beside its value — narrow the window to see it. Both drop the table role where they change display; put role="table", role="row" and role="cell" back if screen-reader users need the grid.

    reveal on the row keeps its controls out of the way until you point at it — hover a row, or tab into one, and they appear. Where the pointer cannot hover they are never hidden. tooltip names an icon-only button on hover and focus, but it is drawn in CSS and assistive tech never sees it, so the aria-label beside it is doing the real work.

    tag gives any element the button's exact appearance and every button variant — they share the same rules, so they cannot drift apart. Only a tag that is an a, button, summary or label gets the hand cursor and the hover, active and focus states; a plain <span tag> never pretends to be clickable.
