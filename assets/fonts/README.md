# Demo fonts

- Unmodified Inter Variable 4.1 by Rasmus Andersson, licensed under the
  [SIL Open Font License 1.1](Inter-OFL.txt). It is the regular theme's font.
  Source: https://github.com/rsms/inter/tree/v4.1/docs/font-files
- Unmodified Roboto Variable, the Latin and Latin Extended subsets, by the
  Roboto Project Authors, licensed under the
  [SIL Open Font License 1.1](Roboto-OFL.txt). It is the Material skin's font.
  Source: https://www.npmjs.com/package/@fontsource-variable/roboto (5.3.0),
  from https://github.com/googlefonts/roboto-classic

The demo hosts these files locally to work offline and avoid third-party font
requests. The library itself does not load fonts or include these assets in its
npm package. Applications can choose their own font through `--font-sans`.
